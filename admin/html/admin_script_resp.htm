说明：

① JSON 接口：域名/plus/mxjx/?url=官方视频地址，接口会自动搜索资源站，返回 JSON，其中 url 为可播放的 m3u8 地址；
② 支持参数：url（官方视频地址）、wd（片名，自动识别失败时使用）、vid（资源 ID）、ep（集数，从 0 开始）；链接带 & 等符号时请先 URL 编码（右上角「测试 JSON 接口」会自动编码）；
③ 未传入链接或资源 ID 时返回：{"code":400,"msg":"缺少vid参数"}；成功返回示例：{"code":200,"msg":"success","url":"m3u8地址","title":"片名","ext":"m3u8"}；
④ 下方可自定义成功与错误的返回字段和内容，字段名与值都可修改，值支持占位符。
可用占位符： {url} 播放地址 · {title} 片名 · {name} 片名 · {ep} 集数名称 · {vid} 资源 ID · {ext} 格式 · {code} 状态码 · {msg} 提示信息
提示：纯数字内容会输出为 JSON 数字（如 200），其余输出为字符串。
