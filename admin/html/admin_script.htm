说明：

① 支持添加多个用户脚本，自动读取其中的解析线路（videoParseList / parseApis / RAW_APIS），线路按接口地址去重后合并使用；
② 「添加脚本」/「更新」会从脚本地址实时拉取并解析线路，「全部更新」可一次刷新全部脚本，过程日志显示在下方「操作日志」面板；
③ 播放入口：域名/plus/script/?url=官方视频地址；直连线路（无损云）会自动搜索资源站并播放 m3u8；直连线路参数必须提供 m3u8 播放源（资源接口返回的播放地址需为 m3u8）；
④ JSON 调用接口：域名/plus/mxjx/?url=官方视频地址；自动搜索资源站并返回 JSON，url 为 m3u8 地址，返回字段可在「返回响应设置」中自定义；
⑤ 「同步到解析线路」会把带接口地址的线路追加到「系统设置 → 解析设置 → 解析线路」，供前台解析使用；
⑥ 对外接口（支持跨域，可独立接入）：域名/plus/script/api.php?list=1 获取线路列表，域名/plus/script/api.php?url=官方视频地址[&line=线路序号] 返回 JSON，type 为 direct（m3u8）/ iframe（内嵌地址）/ popup（新窗口打开）；
⑦ 「导出」把每个脚本源码（.user.js）与清单 scripts.json 写入源码根目录 /MXJB/；「导入」读取该目录恢复脚本（目录不存在时自动创建），更新失败时会自动改用本地源码副本；
⑧ 独立接口 域名/1.php?url=官方视频地址：必须先通过系统防火墙校验，业务代码从 kanju-api 仓库同步到本地，可在本页下方「独立 PHP 接口」中管理。
