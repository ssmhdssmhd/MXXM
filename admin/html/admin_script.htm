说明：

① 脚本解析会读取用户脚本中的解析线路（videoParseList），保存后即可用于解析播放；
② 点击「更新脚本」会从脚本地址实时拉取并解析线路，脚本更新后点一下即可同步；
③ 播放入口：域名/plus/script/?url=官方视频地址；直连线路（无损云）会自动搜索资源站并播放 m3u8；直连线路参数必须提供 m3u8 播放源（资源接口返回的播放地址需为 m3u8）；
④ JSON 调用接口：域名/plus/mxjx/?url=官方视频地址；自动搜索资源站并返回 JSON，url 为 m3u8 地址，返回字段可在「返回响应设置」中自定义；
⑤ 「同步到解析线路」会把带接口地址的线路追加到「系统设置 → 解析设置 → 解析线路」，供前台解析使用。
