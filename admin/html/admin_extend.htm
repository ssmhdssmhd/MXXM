首页 扩展功能 动态密钥 ဂ

扩展功能说明：

① 当前扩展为独立接口 /1.php 提供“固定密钥＋动态临时密钥”双重鉴权；
② 固定密钥由管理员自己保管，不会被自动轮换修改；临时密钥提供给调用方，按设置的周期自动更换为新的 18 位随机字母数字；
③ 更换周期可设置 0-24 小时：0 表示不自动更换，1 表示每小时更换，24 表示每天更换，默认 1 小时；
④ 两种密钥都能调用接口。临时密钥到期后旧密钥立即失效，固定密钥仍可正常使用；
⑤ 无需配置计划任务：打开本页面或接口收到请求时会自动检查，到期立即更换；
⑥ 开启动态 JSON 接口后，APP 可通过 /MXDTKEY.json 自动获取当前临时密钥，避免把会变化的密钥写死在安装包中；接口同步使用系统防火墙并记录调用日志。
