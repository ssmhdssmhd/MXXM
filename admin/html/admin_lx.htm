轮训接口说明：

① 按顺序请求下方多条解析线路，返回第一条成功解析出 url 的结果，前一条失败自动切换下一条；
② 线路全部在下方可视化设置，保存后立即生效，无需修改代码；
③ 代码与配置位于项目 LX/ 目录，配置文件 LX/config.php 不会随在线更新覆盖；
④ 调用地址：域名/LX/?url=官方视频地址，可加 &line=2 指定线路；
⑤ 每次调用会写入「日志与调用 → 调用日志」，模块为「轮训接口」。
