首页 广告设置 基本设置 ဂ

使用说明:


本功能用于在调用解析线路（解析接口）时向前台播放广告；
系统会自动识别电脑端 / 移动端，分别调用对应的广告代码；
广告代码支持 HTML（图片、视频、JS 均可），倒计时结束后自动进入解析播放，可设置是否允许跳过；
设置关闭或广告代码为空时，不显示广告，保持原有解析体验；
「解析页去广告」用于屏蔽解析接口页面自带的弹窗广告 / 劫持跳转，不影响自有广告的展示。
广告开关
>
开启后，前台点击解析线路时先播放广告
单位：秒，0 表示不等待直接播放
>
允许时，用户可点击右上角按钮跳过广告
解析页去广告（屏蔽解析接口页面中的广告）
>
开启后，前台解析 iframe 会自动限制解析页的广告行为
若解析页需要登录 / 支付弹窗，请选择「兼容」
说明：跨域页面无法直接删除其内部元素，本功能通过限制解析页的弹窗、顶层跳转等广告行为实现屏蔽；如解析站自身支持去广告参数，可在「附加参数」中填写。
