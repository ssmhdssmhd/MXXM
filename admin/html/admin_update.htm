使用说明:


本功能直接从远程仓库实时拉取最新代码，实现一键更新、免维护;
点击「检查更新」可对比当前版本与远程仓库版本，如实显示最新提交信息;
点击「立即更新」将从仓库下载最新代码并覆盖到本地，不会覆盖 save/ 目录下的配置与数据，请放心使用;
更新依赖服务器 PHP 的 curl 与 ZipArchive 扩展，并需具备根目录写入权限。
