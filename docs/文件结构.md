## 顶层目录

```
MXSMCK/
├── README.md              # 项目总览（四大组件介绍 + 快速开始）
├── CHANGELOG.md           # 版本更新日志
├── VERSION                # 当前版本号
├── docs/
```

> 说明：`app/` 为电视端 APK 反编译工程（含 `smali/`、`assets/`、`res/` 等），核心修改文件为

## 一、控制端（control/）—— App 的后端

> 运行环境：PHP ≤ 7.3 + MySQL。核心：`zk.php` 是 App 的对接主接口。

### 根目录入口文件

| 路径 | 说明 |
|------|------|
| `index.php` | 控制端首页入口（按模板渲染首页） |
| `index.html` | 静态引导页 |
| `zk.php` | **App 主对接接口**，校验签名后输出配置 JSON（首页频道、播放源、功能开关） |
| `Client.php` | 视频解析客户端接口（解析线路 / 自动嗅探真实播放地址） |
| `api.php` | 通用 API 入口（带 SQL 注入与 XSS 过滤），根据 `act` 分发功能 |
| `api1.php` | 备用 API 入口 |
| `app.php` | App 数据入口 |
| `login.php` | 用户扫码登录页面 |
| `order.php` | 订单管理（查询/生成订单） |
| `pay.php` | 支付发起（选择支付方式） |
| `ali_notify.php` | 支付宝支付异步回调 |

## 三、电视端 App（app/）

> 结构为 apktool 反编译产物，核心拆分三部分：`smali`（代码）、`res`（资源）、`assets`（配置）。

| 路径 | 说明 |
|------|------|
| `AndroidManifest.xml` | 应用清单（包名、权限、页面注册） |
| `smali*/*/com/shenma/tvlauncher/Api.smali` | **对接配置类**（修改对接地址的核心位置） |
| `assets/config.properties` | 配置文件（键值对） |
| `assets/index.html` / `search.html` | 内嵌网页 |
| `res/` | 图片、XML 布局、动画等资源 |
| `lib/` | 播放器 so 库（ijk、exo、kodi、ali、乐视 p2p） |

### App 页面与 smali 位置对照

| 页面 | smali 位置 | 功能 |
|------|------------|------|
| 启动页 | `SplashActivity` | 加载配置、检查更新、跳转首页 |
| 首页 | `HomeActivity2` | 频道导航、推荐、分类 |
| 点播播放 | `VideoPlayerActivity` | 影片播放、选集、广告 |
| 直播播放 | `TVLivePlayer` | 电视直播、EPG 节目单 |
| 搜索 | `SearchActivity` | 影片/直播搜索 |
| 用户中心 | `UserActivity` | 登录、会员、收藏、历史 |
| 设备授权 | `EmpowerActivity` | 设备激活/授权 |
| 设置 | `SettingInvActivity` | 应用设置 |
| 后台服务 | `MyService` | 后台数据同步 |

### 对接配置（Api.smali 需修改）

| 字段 | 对应 | 填法 |
|------|------|------|
| `MAIN_JUHETV_URL` | 控制端主接口 | `https://你的域名/zk.php` |
| `CLOUD_JUHETV_URL` | 云接口（可空） | 留空或填云地址 |
| `JUHEQQ692000321_ID` | 控制端应用编号 | 控制端后台创建的应用 ID |
