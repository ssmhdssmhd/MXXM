# 聚合神马 TV 套件 · 部署教程（新手版）

> 适用版本：v.0.0.1 · 更新时间：20261001
> 目标读者：没有任何服务器经验的完全新手

---

## 一、需要准备什么

| 物品 | 说明 | 费用 |
|------|------|------|
| 一台云服务器 | 阿里云/腾讯云/华为云均可，2 核 2G 以上更流畅 | 约几十元/月 |
| 一个域名 | 已在服务器商后台解析到服务器 IP（A 记录） | 约几十元/年 |
| 宝塔面板 | 免费服务器管理面板，网页操作 | 免费 |
| 手机/电脑 | 操作面板、上传文件 | - |

> 说明：没有域名也可以先用服务器 IP 跑通，只是访问地址不带 `https`。

## 二、服务器基础准备

### 2.1 安装宝塔面板

1. 用 SSH 工具（如 XShell / FinalShell）连接服务器，执行：

```bash
yum install -y wget && wget -O install.sh http://download.bt.cn/install/install_6.0.sh && bash install.sh
```

（Ubuntu/Debian 系统请到宝塔官网获取对应安装命令）

2. 安装完成后，面板会打印访问地址和默认账号密码，保存好。
3. 浏览器打开面板地址，登录后在"软件商店"安装：
   - **PHP 7.3**（注意：控制端要求 PHP ≤ 7.3，CMS 要求 ≥ 5.5，所以选 7.3 最合适）
   - **MySQL 5.7**
   - **Nginx**
   - **phpMyAdmin**（可选，方便管理数据库）

### 2.2 解析域名

1. 在域名注册商（如阿里云万网）控制台 → 域名解析 → 添加解析：
   - 主机记录：`@`（或 `mxsmck`）
   - 记录类型：`A`
   - 记录值：你的服务器 IP
2. 等待几分钟生效（可用 `ping 你的域名` 验证）。

## 三、部署控制端（App 的后端）

### 3.1 创建站点

1. 宝塔面板 → 网站 → 添加站点：
   - 域名：`你的域名`（或先用 IP）
   - PHP 版本：**7.3**
   - 创建 FTP、创建数据库（数据库名如 `smtv`，账号 `smtv`，密码自定义）
2. 记录好你创建的**数据库名、账号、密码**。

### 3.2 上传文件

1. 找到本套件 `control` 目录（聚合神马控制端源码）。
2. 全部上传到网站根目录，例如 `/www/wwwroot/你的域名/`。
3. 宝塔 → 文件 → 给以下目录设置权限 755（重要）：
   - `Cache/`
   - `data/`
   - `install/`
   - `runtime/`（如有）

### 3.3 修改数据库配置

打开 `include/db.config.php`，改为你刚创建的数据库信息：

```php
define('DB_HOST','localhost');      // 数据库连接地址，保持默认
define('DB_USER','smtv');           // 改成你的数据库账号
define('DB_PASSWD','你的密码');     // 改成你的数据库密码
define('DB_NAME','smtv');           // 改成你的数据库名
define('DB_PRE','yyys_');           // 数据表前缀，默认 yyys_ 不要改
```

### 3.4 导入数据库

1. 宝塔 → 数据库 → 找到你的库 → 导入。
2. 导入文件：控制端数据库 SQL（含 `app`、`main`、`analysis_set` 等 `yyys_` 前缀表，见附录 A）。
3. 若你手头没有控制端 SQL 文件，可让安装向导自动建表：访问 `http://你的域名/install` 按提示执行安装。

### 3.5 验证安装

1. 浏览器访问 `http://你的域名/index.php`，出现控制端首页说明部署成功。
2. 访问 `http://你的域名/install`，若已生成 `install/install.lock` 则安装完成。
3. 访问 `http://你的域名/admin` 登录管理后台，**创建一个应用**，记下返回的**应用编号（ID）**，这是 App 对接的凭证。

## 四、部署 CMS（内容管理）

### 4.1 创建第二个站点

1. 宝塔 → 网站 → 添加站点（域名可用 `cms.你的域名` 或二级目录）。
2. PHP 版本选 **7.3**，创建数据库（如 `mxsmck_cms`）。

### 4.2 上传文件

1. 找到本套件 `cms` 目录（聚合神马 CMS 纯净版）。
2. 全部上传到该网站根目录。
3. 设置 `application/`、`runtime/`、`upload/`、`static/` 目录权限 755（可写）。

### 4.3 导入数据库

1. 宝塔 → 数据库 → 导入 `mysql_data_e2xzT.sql`（包含 `mac_vod`、`mac_type`、`mac_admin` 等 mac_ 前缀表）。

### 4.4 执行安装

1. 浏览器访问 `http://cms.你的域名/install.php`。
2. 按向导填写数据库信息、后台管理员账号密码。
3. 安装完成后**立即做两件事**：
   - 把后台入口 `_admin.php` 改名为随机名字，如 `x7f3k9.php`（苹果 CMS 官方提示，防止被黑客扫描攻击）
   - 删除或改名 `install.php`

### 4.5 维护内容

1. 访问后台 `http://cms.你的域名/x7f3k9.php` 登录。
2. 在"影片管理"中手动添加影片，或使用"采集"功能批量导入资源。
3. 分类、演员、文章等均可在后台管理。

## 五、打包 App 并修改对接地址

### 5.1 修改对接地址

找到 App 源码中的 `smali_classes2/com/shenma/tvlauncher/Api.smali`，修改三个字段：

```
MAIN_JUHETV_URL    = https://你的域名/zk.php      （主对接地址）
CLOUD_JUHETV_URL   = （可留空）                    （云端接口）
JUHEQQ692000321_ID = 控制端后台创建的应用编号        （App 凭证）
```

### 5.2 云端编译（推荐，无需本地环境）

本套件推荐使用 **GitHub Actions** 云端编译：

1. 把 App 源码推送到你的 GitHub 仓库。
2. 在仓库根目录添加 Actions 工作流（编译 APK，产出 `MXSMCK.v0.0.1.apk` 格式的安装包）。
3. 推送代码即自动触发编译，完成后在 Actions 产物中下载 APK。

### 5.3 本地编译（备用方案）

需要本机安装 Java 8+ 与 apktool：

```bash
apktool b app/ -o MXSMCK.v0.0.1.apk
```

> 注意：重新打包需重新签名，否则无法安装。

### 5.4 安装到电视

1. 将 APK 拷贝到 U 盘，插入电视盒子安装。
2. 或用 TV 盒子的"当贝市场/悟空遥控器"等工具远程安装。
3. 打开 App，如能正常显示首页数据即对接成功。

## 七、常见问题（FAQ）

**Q1：访问 zk.php 提示"PHP版本需要<=7.3"？**
A：控制端只支持 PHP 7.3 及以下，请在宝塔站点设置中把 PHP 版本切到 7.3。

**Q2：提示"请先安装"？**
A：删除 `install/install.lock` 后重新访问 `install` 目录，或检查数据库是否导入成功。

**Q3：App 打开显示空白/无数据？**
A：检查三点：① `Api.smali` 的对接地址是否填写正确；② 应用编号是否存在；③ 服务器是否开放 80/443 端口。

**Q4：支付回调失败？**
A：检查 `ali_notify.php` / `wx_notify.php` / `qq_notify.php` 中配置的商户密钥是否正确，且服务器能外网访问。

**Q5：CMS 后台入口被扫描攻击？**
A：把 `_admin.php` 改名即可，同时开启宝塔的网站防火墙。

**Q6：打包后的 APK 提示签名冲突？**
A：卸载旧版再安装，或使用与旧版相同的签名文件。
